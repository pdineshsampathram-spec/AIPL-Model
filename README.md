# IPL Match Outcome Forecast

## Overview
This project contains the machine learning pipeline and notebook submissions for the **AIPL 2026 IPL Match Forecast Competition**, an AI competition hosted by **NxtWave** on Kaggle. The goal of the competition is to predict the match outcomes (in 4 distinct probability classes) of historical and upcoming IPL matches.

## Project Structure
- `IPL_Winner_Prediction.ipynb`: The main, self-contained Jupyter Notebook that handles data preprocessing, Exploratory Data Analysis (EDA), feature engineering, and constructs the predictive baseline model.
- `train_bundle/`: This directory contains the original dataset provided by the competition organizers. It includes the historical ball-by-ball IPL dataset, match schedules, and sample submission templates.

## How to Use
To run the model:
1. Ensure your Python environment has the necessary libraries installed (`pandas`, `numpy`, `matplotlib`, `seaborn`, `scikit-learn`).
2. Open `IPL_Winner_Prediction.ipynb` using Jupyter Notebook or your preferred IDE.
3. Run the notebook sequentially to reproduce the visualizations and generate the final output `.csv` submission file.
